# Low Altitude Operations Platform (Mock Version)

低空作業營運系統 — Prototype 展示版本

---

## 📌 專案說明

本版本為 **展示用 Mock Prototype**。

目的是展示 Low Altitude Operations Platform 的整體架構設計與決策流程，
並非完整後端實作版本。

本系統定位為：

> 低空高風險作業的「任務生成 + 風險控制 + 合規留痕」決策中樞。

---

## 🎯 本次 Mock 版本目標

展示以下能力：

1. 地址輸入 → 空域解析
2. 建物資料輸入 → 任務生成
3. 天候判斷 → 風險分級（W × R）
4. 作業時間預測模型
5. 報價生成引擎
6. 人員與設備資格檢查
7. 任務規劃書自動生成

本版本重點在於：

- 決策流程可視化
- 風險邏輯展示
- 作業時間模型展示
- 報價結構展示

## 🌦 風險分級模型

本分級模型用於協助客戶理解報價單中所標示之天候類型代碼（W）與作業風險等級（R）之意義與適用情境。
相關分級目的在於提升作業安全、品質穩定性及風險透明度。

### 一、天候類型代碼說明（W）

| 代碼 | 天候類型名稱 | 常見發生時期 | 客戶可理解說明 |
|---|---|---|---|
| W0 | 穩定高壓晴朗型 | 全年不定 | 天氣穩定、降雨機率低，適合作業 |
| W1 | 東北季風型 | 11 月–3 月 | 冬季常見型態，北部與迎風面易陰雨、風較強 |
| W2 | 鋒面掃過型 | 春、秋季 | 降雨系統會移動，雨勢通常不會長時間停留 |
| W3 | 梅雨滯留型 | 5–6 月 | 連續多日降雨，地面潮濕、作業彈性低 |
| W4 | 午後熱對流型 | 6–9 月 | 夏季午後局部雷陣雨，變化快速 |
| W5 | 颱風外圍環流型 | 7–10 月 | 受颱風影響，風向與雨勢不穩定 |

### 二、作業風險等級說明（R）

| 代碼 | 風險等級 | 作業狀態說明 | 客戶應理解重點 |
|---|---|---|---|
| R0 | 低風險 | 天氣穩定，可依正常流程作業 | 作業時間與完成度可預期 |
| R1 | 輕度風險 | 天氣略有變數，需調整作業時段 | 可能需配合指定時段施工 |
| R2 | 中度風險 | 天氣變化較快，需即時監控 | 作業可能中斷或分段完成 |
| R3 | 高風險 | 作業安全性不足 | 原則不安排飛行作業 |
| R4 | 禁飛等級 | 不符合安全條件 | 作業將延期或取消 |

### 三、報價單代碼顯示方式說明

報價單中將以 `W × R` 代碼標示本案評估之天候與作業風險狀態。

| 報價單標示 | 意義說明 |
|---|---|
| W0–R0 | 天氣穩定，低風險作業條件 |
| W1–R1 | 冬季東北季風期間，輕度風險 |
| W1–R2 | 東北季風影響明顯，作業彈性較低 |
| W2–R1 | 鋒面型降雨，視雨帶移動情況施工 |
| W4–R2 | 夏季午後雷陣雨型態，需即時調整 |

### 四、重要說明事項

1. 天候風險分級並非代表是否一定下雨，而是評估：
   - 作業是否可預測
   - 是否容易中斷
   - 是否需要預留待命與安全控管成本
2. 實際作業仍將以作業當日即時氣象狀況為最終判斷依據。
3. 本分級制度用於確保：
   - 人員安全
   - 設備完整
   - 建物與周邊環境之風險控管

> 本公司以天候風險分級制度進行報價與排程，目的是讓作業條件與風險透明化，而非臨時調整或主觀判斷。

## ⏱ 作業時間預測模型（展示版本）

Mock 模型示範：

```
實際效率 =
    標準效率
    × 高度修正係數
    × 風速修正係數
    × 結構複雜度係數
```

輸出結果：

- 實際效率
- 預估總作業時間
- 建議作業天數
- 中斷預留比例

---

## 💰 報價引擎（展示邏輯）

Mock 計算流程：

```
最終單價 =
    基礎單價
    + 單面加成
    + 整案加成

總價 =
    面積 × 單價 × 作業倍率
```

> ⚠️ 本版本僅展示計算結構，不包含實際商業參數。
