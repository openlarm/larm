# Low Altitude Operations Platform (Mock Version)

低空作業營運系統 — Prototype 展示版本

---

## 📌 專案說明

本版本為 **展示用 Mock Prototype**。

目的是展示 Low Altitude Operations Platform 的整體架構設計與決策流程，
並非完整後端實作版本。

本系統定位為：

> 低空高風險作業的「任務生成 + 風險控制 + 合規留痕」決策中樞。

---

## 🎯 本次 Mock 版本目標

展示以下能力：

1. 地址輸入 → 空域解析
2. 建物資料輸入 → 任務生成
3. 天候判斷 → 風險分級（W × R）
4. 作業時間預測模型
5. 報價生成引擎
6. 人員與設備資格檢查
7. 任務規劃書自動生成

本版本重點在於：

- 決策流程可視化
- 風險邏輯展示
- 作業時間模型展示
- 報價結構展示

---

## 🧠 系統定位

這不是：

- 排班系統
- CRM 系統
- 清潔管理工具

這是：

> **Low Altitude Operations OS**
> 低空作業決策作業系統

---

## 🏗 支援任務類型

| 任務類型 | 說明 |
|---|---|
| 建物清潔 | 高樓外牆清潔作業，含無人機輔助水洗 |
| 太陽能板清潔 | 屋頂或地面型光電板表面清潔 |
| 外牆噴塗 | 建物立面防水塗料或隔熱塗料施工 |
| 外牆巡檢 | 建物外立面裂縫、滲水、損壞影像記錄 |

---

## 🔄 展示流程（Mock Flow）

```
1.  輸入地址
2.  系統自動解析空域狀態
3.  輸入建物基本資料
4.  系統產生任務類型判定
5.  天候分類（W0–W5）
6.  作業風險分級（R0–R4）
7.  作業時間預測
8.  報價生成
9.  團隊與設備檢核
10. 任務規劃書產出
```

---

## 🌦 風險分級模型

### 天候類型（Weather Type）

| 代碼 | 天候描述 |
|---|---|
| W0 | 穩定高壓 |
| W1 | 東北季風 |
| W2 | 鋒面掃過 |
| W3 | 梅雨滯留 |
| W4 | 午後熱對流 |
| W5 | 颱風外圍 |

### 作業風險等級（Risk Level）

| 代碼 | 風險等級 |
|---|---|
| R0 | 低風險 |
| R1 | 輕度風險 |
| R2 | 中度風險 |
| R3 | 高風險 |
| R4 | 禁飛 |

### 最終輸出格式：`W × R`

例如：

```
W1–R2
```

---

## ⏱ 作業時間預測模型（展示版本）

Mock 模型示範：

```
實際效率 =
    標準效率
    × 高度修正係數
    × 風速修正係數
    × 結構複雜度係數
```

輸出結果：

- 實際效率
- 預估總作業時間
- 建議作業天數
- 中斷預留比例

---

## 💰 報價引擎（展示邏輯）

Mock 計算流程：

```
最終單價 =
    基礎單價
    + 單面加成
    + 整案加成

總價 =
    面積 × 單價 × 作業倍率
```

> ⚠️ 本版本僅展示計算結構，不包含實際商業參數。

## 👥 資格與設備檢核

Mock 展示項目：

- 飛手等級驗證
- 證照有效期限檢查
- 夜間資格檢查
- 設備校準狀態
- 設備健康狀態

若條件不足：

> → 系統標示**需升級審核**或**禁止生成任務**。
