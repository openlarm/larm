# 報價模型說明 — 無人機外牆清潔

**版本：** v1
**日期：** 2026-02-20

> **單位說明**
> - 單價加成：NTD / ㎡
> - 倍率：整案最後套用
> - 面積：㎡

## B｜特定清潔面「單價加成」（只影響該面）

| 項目 | 條件 | 單價加成（NTD / ㎡） |
|---|---|---|
| 是否需要封路 | 是 | +4 |
| 建物周邊空間不足 | < 5m | +6 |
| 高風險環境 | 高壓電 / 基地台 | +7 |
| 水源供應不足 | 需自備 | +7 |
| 電力供應不足 | 需自備 | +7 |
| 屋頂吊掛條件不佳 | 女兒牆深、寬 / 不可使用屋頂 | +12 |
| 外牆結構複雜度（無） | — | +0 |
| 外牆結構複雜度（輕） | — | +4 |
| 外牆結構複雜度（中） | — | +6 |
| 外牆結構複雜度（重） | — | +8 |

|---|---|

---

## D｜整案倍率（最後套用）

| 項目 | 條件 | 倍率 |
|---|---|---|
| 作業時間限制 | 無限制 | ×1.0 |
| 作業時間限制 | 週末 | ×1.2 |
| 作業時間限制 | 夜間 | ×1.5 |
| 急件需求 | 30 天內 | ×1.33 |
| 樓層高度 | > 10F | ×1.3 |
| 樓層高度 | > 20F | ×2.0 |
| 樓層高度 | > 30F | ×3.0 |
| 氣候風險等級 | R0 | ×1.0 |
| 氣候風險等級 | R1 | ×1.05 |
| 氣候風險等級 | R2 | ×1.15 |
| 氣候風險等級 | R3 | ×1.40（備援待命費） |
| 氣候風險等級 | R4 | 不報價 / 延期 |

> 多項倍率需同時套用時，以**乘積**計算（非相加）。
> 例：夜間 × 急件 × 20F 以上 = 1.5 × 1.33 × 2.0 = **3.99×**

---

## E｜計算公式

```
─── 單面計算 ───────────────────────────────────────────

單面單價 = 基礎單價（A）
           + Σ 單面加成（B）
           + Σ 整案加成（C）

單面小計 = 單面面積（㎡） × 單面單價

─── 整案計算 ───────────────────────────────────────────

整案小計 = Σ 各面小計

整案倍率 = Π 適用倍率（D）

最終報價 = 整案小計 × 整案倍率
```

## F｜範例計算

**場景：** 台北市商業大樓，北面外牆清潔，25 樓，夜間施工，水垢＋黑黴污染，無封路需求，外牆結構複雜度輕。

| 項目 | 數值 |
|---|---|
| 面積 | 800 ㎡ |
| A 基礎單價（商業大樓） | 30 |
| B 外牆結構複雜度（輕） | +4 |
| C1 清潔劑（中性） | +3 |
| C2 污染類型（水垢 + 黑黴） | +12（7 + 5，未達上限） |
| **單面單價合計** | **49 NTD / ㎡** |
| 單面小計 | 800 × 49 = **39,200 NTD** |

| 倍率項目 | 倍率 |
|---|---|
| 夜間作業 | ×1.5 |
| 樓層（> 20F） | ×2.0 |
| 氣候風險 R1 | ×1.05 |
| **整案倍率（乘積）** | **×3.15** |

```
最終報價 = 39,200 × 3.15 = 123,480 NTD
```

> ⚠️ 本範例為展示用途，商業參數請參照 `pricing_params_v1.csv`。
