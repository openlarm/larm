# Low Altitude Operations Platform

## Product Specification v1.0 (Mock / Presentation Version)

---

## 1. Product Overview

Low Altitude Operations Platform 是一套專為高風險低空作業設計的決策系統。

本產品不是清潔管理工具。
不是排班系統。
不是 CRM。

本產品定位為：

> 低空高風險作業的「任務生成 + 風險控制 + 合規留痕」操作系統。

---

## 2. Problem Statement

高樓無人機作業目前存在以下問題：

- 作業可行性依賴人工經驗判斷
- 風險分級缺乏標準模型
- 天候與效率無量化模型
- 報價與風險無直接連動
- 人員與設備資格缺乏強制門檻
- 事故後難以回溯決策過程

這導致：

- 不可預測風險
- 毛利不穩定
- 合規風險提高
- 無法規模化複製

---

## 3. Product Vision

建立一個可擴展至多種低空任務類型的作業決策核心：

- 外牆清潔
- 外牆巡檢
- 噴塗
- 太陽能板清潔
- 高樓巡航

讓低空作業具備：

- **可量化**風險
- **可預測**工期
- **可版本化**決策
- **可回溯**審計

---

## 4. Core System Flow

```
1.  輸入地址
2.  空域可行性判斷
3.  建物資料輸入
4.  風險分級（W × R）
5.  作業時間預測
6.  報價生成
7.  團隊資格檢核
8.  設備健康檢核
9.  任務規劃書生成
10. 空域申請資料產出
```

## 5. Core Modules

---

### 5.1 Address & Airspace Evaluation

**功能：**

- 地址解析
- 經緯度取得
- 海拔資訊
- 空域限制判斷

**輸出：**

| 結果 | 說明 |
|---|---|
| 可作業 | 無空域限制，可直接進行任務規劃 |
| 需申請 | 位於管制空域，須取得飛航許可 |
| 禁飛 | 不符合作業條件，任務無法生成 |

---

### 5.2 Risk Classification Engine

**天候類型（Weather Type）**

| 代碼 | 說明 |
|---|---|
| W0 | 穩定高壓 |
| W1 | 東北季風 |
| W2 | 鋒面掃過 |
| W3 | 梅雨滯留 |
| W4 | 午後熱對流 |
| W5 | 颱風外圍 |

**作業風險等級（Risk Level）**

| 代碼 | 說明 |
|---|---|
| R0 | 低風險 |
| R1 | 輕度風險 |
| R2 | 中度風險 |
| R3 | 高風險 |
| R4 | 禁飛 |

**輸出格式：** `W × R`

並產出：

- Go / Conditional / No-Go
- 升級審核條件
- 必要安全控制措施

---

### 5.3 Time Estimation Engine

**核心目的：**

量化作業所需時間，避免單純依賴面積估算。

**模型結構：**

```
實際效率 =
    標準效率
    × 高度係數
    × 風速係數
    × 複雜度係數
    × 污染係數
    × 作業時段係數

總作業時間 =
    （有效面積 ÷ 實際效率）
    + 架設時間
    + 收撤時間
    + 法定休息時間
    + 中斷預留時間
```

**輸出：**

- 總工時
- 建議作業天數
- 中斷風險比例

---

### 5.4 Pricing Engine

報價由以下結構組成：

1. 基礎單價
2. 單面加成
3. 整案加成
4. 作業倍率（時間 / 高樓 / 急件 / 氣候）

**公式結構：**

```
總價 =
    Σ【面積 ×（基礎單價 + 加成）】
    × 作業倍率
```

**特性：**

- 與風險分級連動
- 支援低消
- 支援偏遠加價
- 支援大型案場折扣
- 參數版本化

> 詳見 `pricing_model.md` 與 `pricing_params_v1.csv`。

---

### 5.5 Certification & Permission Control

任務生成前必須檢查：

| 項目 | 說明 |
|---|---|
| 飛手等級 | 符合任務所需資格等級 |
| 證照有效期限 | 未過期 |
| 夜間資格 | 夜間作業時必須具備 |
| 高樓資格 | 特定樓層以上作業時必須具備 |
| 設備校準狀態 | 校準紀錄在有效期限內 |
| 設備健康狀態 | 無待處理維修項目 |

若條件不足：

> → 阻止任務生成，或標示需升級審核。

---

### 5.6 Equipment Lifecycle Management

追蹤：

- 使用時數
- 維修紀錄
- 校準紀錄
- 保養提醒

設備不符合狀態時：

> → 禁止指派至任何任務。

---

### 5.7 Mission Plan Generator

自動生成任務規劃書，包含：

| 欄位 | 說明 |
|---|---|
| 任務摘要 | 任務類型、地點、預計日期 |
| 建物資訊 | 樓層、面積、結構特徵 |
| 風險等級 | W × R 分級結果 |
| 作業時間預測 | 總工時、建議天數、中斷預留 |
| 人員配置 | 飛手、地勤、督導 |
| 設備清單 | 機體、電池、工具 |
| 空域狀態 | 可行性判定、申請狀態 |
| 規則版本號 | 所套用之規則集版本 |

---

### 5.8 Audit & Evidence

所有決策需記錄：

- 規則版本
- 輸入資料
- 計算結果
- 審核流程
- 任務狀態變更

> **不可修改歷史資料。** 所有紀錄為只寫（append-only）。

---

## 6. Design Principles

1. 所有規則必須**版本化**
2. 所有決策必須**可回溯**
3. 核心演算法**不可暴露**
4. 任務必須**通過門檻**才能生成
5. 系統必須**可擴展**至多任務類型
