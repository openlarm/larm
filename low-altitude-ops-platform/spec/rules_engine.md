# Rules Engine — W × R Risk Classification

**版本：** ruleset_v1.0
**日期：** 2026-02-20
**用途：** 定義天候類型（W）與作業風險等級（R）的對應邏輯、決策判斷與商業連動

---

## 一、基礎定義

### W — Weather Type（天候型態）

| 代碼 | 類型 | 特徵 |
|---|---|---|
| W0 | 穩定高壓 | 低風、低雨、穩定 |
| W1 | 東北季風 | 穩定風向、陣風偏高 |
| W2 | 鋒面掃過 | 降雨移動型、不穩定 |
| W3 | 梅雨滯留 | 連續降雨、地面潮濕 |
| W4 | 午後熱對流 | 短時雷陣雨、變化快 |
| W5 | 颱風外圍 | 強陣風、降雨不穩 |

### R — 作業風險等級

| 代碼 | 意義 | 作業狀態 |
|---|---|---|
| R0 | 低風險 | 正常可作業 |
| R1 | 輕度風險 | 可作業，需監控 |
| R2 | 中度風險 | 條件式作業 |
| R3 | 高風險 | 原則不排 |
| R4 | 禁飛 | 禁止作業 |

---

## 二、W × R 對應矩陣（公開展示版）

此矩陣代表「天候型態下的風險可達範圍」。

| W \ R | R0 | R1 | R2 | R3 | R4 |
|---|---|---|---|---|---|
| W0 | ✅ | ✅ | ⚠ | ❌ | ❌ |
| W1 | ❌ | ✅ | ⚠ | ⚠ | ❌ |
| W2 | ❌ | ⚠ | ⚠ | ⚠ | ❌ |
| W3 | ❌ | ❌ | ⚠ | ⚠ | ❌ |
| W4 | ❌ | ⚠ | ⚠ | ⚠ | ❌ |
| W5 | ❌ | ❌ | ⚠ | ⚠ | ❌ |

**圖例**

| 符號 | 意義 |
|---|---|
| ✅ | 此天候下此風險等級可出現（正常） |
| ⚠ | 此天候下此風險等級可出現（條件式） |
| ❌ | 此天候下此風險等級不應出現 |

**解釋邏輯**

- **W0（穩定高壓）** 理論上可達 R0 或 R1，視建物條件而定
- **W1（東北季風）** 通常最低為 R1，陣風條件可升至 R2
- **W3（梅雨）** 不會出現 R0，連續降雨導致最低為 R2
- **W5（颱風外圍）** 幾乎不會低於 R2，強陣風通常達 R3

---

## 三、內部決策矩陣（操作層）

> 此層為系統內部判斷依據，對外顯示 Go / Conditional / No-Go 結果，不顯示內部邏輯細節。

| W × R | 作業判斷 | 是否需升級審核 | 控制措施 |
|---|---|---|---|
| W0–R0 | GO | 否 | 正常流程 |
| W0–R1 | GO | 否 | 風速監控 |
| W1–R1 | GO | 否 | 增加觀察手 |
| W1–R2 | Conditional | 是 | 縮短飛行時段 |
| W2–R2 | Conditional | 是 | 分段作業 |
| W3–R2 | Conditional | 是 | 地面防滑措施 |
| W4–R2 | Conditional | 是 | 即時雷達監控 |
| W5–R2 | Conditional | 是（主管簽核） | 主管簽核 + 縮短時段 |
| 任意–R3 | No Schedule | 是 | 原則不排，可申請例外 |
| 任意–R4 | No-Go | 不可 | 禁飛，任務不可生成 |

## 四、W × R 與報價連動

W 本身不直接影響報價倍率；W 影響 R，R 決定報價倍率。

| 風險等級 | 報價倍率 | 說明 |
|---|---|---|
| R0 | ×1.00 | 正常作業，無附加 |
| R1 | ×1.05 | 輕度監控成本 |
| R2 | ×1.10 – ×1.20 | 條件式作業，備援待命費 |
| R3 | 不排 | — |
| R4 | 禁止 | — |

> R2 倍率範圍由具體控制措施複雜度決定，詳見 `pricing_params_v1.csv`（`weather_risk_r2`）。

## 五、版本化說明

- 所有任務評估時，系統必須記錄所使用的 `ruleset_version`
- 規則更新時，需建立新版本檔案（`ruleset_v2.json`），舊版本保留不刪除
- 機器可讀版本見 `ruleset_v1.json`
